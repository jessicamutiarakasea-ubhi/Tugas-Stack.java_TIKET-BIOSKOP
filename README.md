📃Deskripsi 

Program ini merupakan transaksi tiket bioskop menggunakan struktur data Stack pada Java dengan konsep LIFO (Last In First Out), yaitu data terakhir yang masuk akan keluar lebih dulu. Data disimpan menggunakan array dan variabel top.

⚙️Cara Kerja Program

▫️push() "menambahkan data tiket ke stack".

▫️peek() "melihat data paling atas tanpa menghapusnya".

▫️pop() "menghapus data paling atas".

▫️tampilkanStack() "menampilkan seluruh isi stack".

▫️Program menambahkan beberapa tiket, menampilkan isi stack, lalu membatalkan satu transaksi
